## Project Overview
This project analyzes online retail transaction data to discover sales patterns, understand customer behavior, segment customers, detect unusual customer-level behavior, and forecast monthly revenue.

## Key Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Revenue and product analysis
- Country and day-of-week analysis
- RFM customer analysis
- K-Means customer segmentation
- Isolation Forest anomaly detection
- Random Forest monthly sales prediction
- Automated business insights

## Dataset
The project uses the **UCI Online Retail dataset**.

Official dataset page:
https://archive.ics.uci.edu/dataset/352/online+retail

The UCI page reports 541,909 transactions covering 01-Dec-2010 to 09-Dec-2011. The dataset is licensed under CC BY 4.0.

## Setup
1. Install Python 3.
2. Open a terminal in this project folder.
3. Run:
```bash
pip install -r requirements.txt
```
4. Start Jupyter:
```bash
jupyter notebook
```
5. Open `Deekshitha_EcommerceCustomerIntelligence.ipynb`.
6. Run all cells from top to bottom.

The notebook downloads the dataset through the `ucimlrepo` package, so the Excel dataset itself does not need to be uploaded to the internship form.

## Main Methodology
1. Load transaction data.
2. Remove duplicates and invalid sales records.
3. Calculate revenue.
4. Perform EDA.
5. Build RFM customer features.
6. Segment customers using K-Means.
7. Detect customer-level anomalies with Isolation Forest.
8. Train a Random Forest model for monthly revenue prediction.
9. Generate business recommendations.

## Important Note
The numerical outputs, charts, cluster sizes, model metrics, and next-month forecast are generated by running the notebook. Do not replace them with invented values.
